# Native verification historical counterexamples

The same safe assertions fail against the original native library and pass against the current library. Each case runs in a fresh Python process through the unchanged public C ABI. No chain or synthetic verification replacement is involved.

- `trailer`: mutate the final non-newline setup byte. Original initialization accepts it (0); current rejects it (-3).
- `reinit`: initialize the approved setup, then request a nonexistent setup. Original returns success (0); current rejects it (-3).
- `merkle`: the retained K2 proof has 96 leaves and verifies in both libraries (1). Appending one unused 32-byte sibling is accepted originally (1) and rejected currently (-3).

`results.json` records actual commands, exit codes, and library hashes; six logs retain the observations and assertion failures. Run `python3 probe.py LIBRARY APPROVED_SETUP CASE`. The fixture is copied beside the probe for portability; initial execution used its identical original retained path. `altered-setup.txt` is generated by the trailer test.
